# Survival Analysis Thesis

Exploration, data preparation, and survival modelling for OBDeleven product
usage. Python handles cleaning, exploratory analysis, imputation, and
person-interval feature engineering; R handles splitting and survival models.

## Project structure

- `Coding/src/` contains reusable cleaning, processing, imputation, summary,
  and plotting code.
- `Coding/src/constants/` contains column names, thresholds, segment settings,
  plotting styles, and portable data paths.
- `Coding/notebooks/` contains the numbered Python analysis pipeline.
- `Coding/docs/` contains the methodology and design record.
- `Coding/Data/` contains ignored raw and generated CSV files; see its README
  for the expected filenames.
- `Coding/R/` contains the survival-modelling stage and its package notes.

## Python setup

From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab Coding/notebooks
```

On Windows, activate the environment with `.venv\Scripts\activate` instead.
The notebooks locate the `Coding/` project directory automatically when
started from the repository or one of its subdirectories.

## Data setup

CSV data is not committed. Add the source files under `Coding/Data/raw/` as
described in [`Coding/Data/README.md`](Coding/Data/README.md). Interim and final
files are generated by the notebooks.

## Workflow

1. Run the raw-dataset cells in
   `Coding/notebooks/02_data_cleaning_and_saving.ipynb` (loads activity, vehicle,
   and user tables).
2. Run `Coding/notebooks/01_data_exploration.ipynb` to inspect usage
   distributions and validate interval and churn-threshold choices.
3. Run the filtered-dataset cells in notebook `02` to create model-ready
   interim datasets (churn labelled; history truncated at first trigger).
4. Run `Coding/notebooks/04_preparing_data_for_modelling.ipynb` to impute
   vehicle start years and create final 14-day and 28-day person-interval
   feature datasets (grid ends at last activity; last incomplete interval
   dropped after the churn-label shift).
5. Run `Coding/R/survival_modelling.R` for splitting and survival modelling.

The rationale for thresholds, imputation, feature engineering, and the
Python-to-R handoff is maintained in
[`Coding/docs/assumptions_and_reasoning.ipynb`](Coding/docs/assumptions_and_reasoning.ipynb).

## Reproducibility notes

- Data paths are derived from the checked-out repository rather than a
  machine-specific absolute path.
- Python dependencies are listed in `requirements.txt`; R dependencies are
  listed in `Coding/R/README.md`.
- Raw and generated CSV files remain ignored to keep private or large data out
  of version control.
